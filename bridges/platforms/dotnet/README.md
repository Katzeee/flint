# .NET platform

This guide is for authors integrating a managed host with Flint. Export the managed sources and native core with `flint bridge export csharp`. For Unity installation and use, follow the [Unity guide](../../hosts/unity/README.md).

A host retains one [BridgeManager](src/Flint.Bridge/BridgeManager.cs), composed from its registration identity, runtime description, executor factory, and dispatcher. The manager creates and retains a [Bridge](src/Flint.Bridge/Bridge.cs), which owns the executor, request pump, and [NativeCore](src/Flint.Bridge/NativeCore.cs) binding. The native core owns connection policy and execution admission. The executor handles the host's code and reports output and completion through the supplied callback. The factory cleans up resources if it fails before returning an executor; after it returns, the manager ensures disposal, including when Bridge creation fails.

Connect and Configure create resources on the calling thread when no Bridge exists, so the caller must enter the thread required by the host. Attach instead sends initialization through the dispatcher and waits for registration. When dispatch queues work onto an event loop, call Attach from a worker and keep the event loop running. The dispatcher also receives execution callbacks from the request pump and must return without waiting for another thread to run them. [CallbackQueue](src/Flint.Bridge/CallbackQueue.cs) supports posting callbacks for the host's event loop to drain.

Connect reuses an existing Bridge at the same endpoint; Configure applies settings through the core while retaining the executor. Attach applies settings and shares one timeout budget between initialization and registration. A timeout cancels initialization that is still queued. Initialization already underway can complete after the caller times out, and registration timeout leaves the Bridge available for inspection or reconnection.

Disconnect stops intake and cancels execution still queued in the platform dispatcher, following the shared [core lifetime and resource release contract](../../../docs/contributing.md#ownership). A false return requires another Disconnect after execution finishes. Dispose is terminal teardown for a hosting context being destroyed; it also runs on managed domain unload. Host-specific reload and shutdown hooks belong to the adapter.

[ManagedExecution](src/Flint.Bridge/ManagedExecution.cs) supplies C# method-body source preparation and managed assembly invocation; [ReflectionApi](src/Flint.Bridge/ReflectionApi.cs) binds runtime-discovered APIs and events. Hosts supply compilation, log capture, and application-specific scheduling. Exact interfaces and error types live in the source. Follow the repository [development guide](../../../docs/contributing.md) when building or testing an integration.
